# أوامر الصوت العربية

هذا المشروع يوفّر القدرات إلى Yango Smart Home. فهم الجملة نفسها يتم داخل Yasmina/Yango، وقد يختلف حسب اللغة والحساب.

## أوامر ثبتت عمليًا في النظام المرجعي
- تشغيل وإطفاء التلفزيون.
- فتح Shahid.
- فتح YouTube عبر عبارة سيناريو مميزة.
- Home / الشاشة الرئيسية.
- Yango Play.
- كتم وإرجاع صوت التلفزيون.
- تشغيل وإطفاء الإضاءة والتحكم في السطوع ودرجة الأبيض.

## التطبيقات
المشروع يربط مصادر التلفزيون كالتالي:
- one → YouTube
- two → Shahid
- three → Watch It
- four → Yango Play

### ملاحظة Watch It
فتح التطبيق نفسه عبر ADB تم التحقق منه، لكن مطابقة اسم Watch It صوتيًا لم تكن موثوقة في الحساب المرجعي. لذلك لا تعتبر جملة بعينها مضمونة قبل اختبارها على حسابك.

### الموسيقى والقرآن
Yasmina لديها مشغلها الداخلي. Smart Home API لا يوفّر اعتراضًا عامًا لأي اسم أغنية/قارئ متغير وتحويل النص تلقائيًا إلى بحث YouTube. يمكن إنشاء سيناريوهات ثابتة تفتح YouTube، لكن هذا ليس default media provider حقيقيًا.

## قاعدة الاختبار
وجود السيناريو في الحساب لا يساوي نجاحًا صوتيًا. اعتبر الأمر ناجحًا فقط بعد:
1. سماعه من الميكروفون،
2. وصول action الصحيح إلى provider،
3. وظهور النتيجة الفعلية على الجهاز.
